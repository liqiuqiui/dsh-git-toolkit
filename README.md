# Git Toolkit

DeepSeek Harness（dsh）插件：在会话界面里查看和切换工作区所属的 git 分支。

插件在插件管理器里显示为 **Git Toolkit**。

## 功能

- **新建会话时切换分支**：新会话输入框上方、模式切换控件右侧有一个 `⑂ 分支名 ⌄` 按钮，点开即可看到当前工作区的本地分支并切换。
- **分支按目录折叠**：`fix/released` 会显示为 `fix` 文件夹下的 `released`，点击文件夹行展开或折叠。
- **搜索分支**：浮层顶部可输入关键字过滤。
- **新建分支**：浮层底部的「+ 创建并检出新分支...」会执行 `git checkout -b`。
- **显示远程关联**：每个分支右侧显示它跟踪的远程分支；远程已被删除的分支会标红提示。
- **对话中显示当前分支**：已开始的对话在输入框下方显示一个只读的分支标签，悬停可看完整的远程跟踪名；游离 HEAD 时显示提交短哈希。

工作区不是 git 仓库时，插件不显示任何内容。

## 使用

### 新建会话时选分支

1. 打开新会话页面。
2. 点输入框上方的 `⑂ 分支名 ⌄`。
3. 在浮层中选择分支，或输入关键字搜索。
4. 若要新建分支，点 `+ 创建并检出新分支...`，输入名字后即可创建并切过去。

若工作区有未提交改动导致切换失败，浮层里会直接显示 git 的原始报错，按提示处理后再试。

### 查看当前分支

对话开始后，输入框下方会显示 `⑂ 分支名`，只用来看，不能点击切换。

切换分支是「开会话之前」的决定：如果运行中的对话也能切，点一下就会把工作区从正在执行的 agent 脚下换掉。需要换分支时，请新开一个会话。

## 注意事项

- 只列出和切换**本地分支**，不会 fetch 远端分支。
- 切换分支会改变工作区的当前分支。若有其他会话或 Agent 正在使用同一个工作区，请先确认它们不受影响。
- 分支选择浮层只在 dsh Web UI 中可用。

## 安装

在 dsh profile 的 `package.json` 中加入依赖，并在 `dsh.profile.bundles` 里登记插件名：

```json
{
  "dependencies": {
    "git-toolkit": "link:/path/to/git-toolkit"
  },
  "dsh": {
    "profile": {
      "bundles": ["...", "git-toolkit"]
    }
  }
}
```

装好后重启 dsh。

> 仓库中的 `lib/` 是构建产物（不纳入版本管理）。若更新了源码，需在仓库里执行 `pnpm install && pnpm build` 重新生成；之后刷新页面即可看到客户端改动，Host 侧改动需完全退出并重开 dsh。
>
> 开发时可用 `pnpm watch:client` 监听客户端源码并自动重新打包。
